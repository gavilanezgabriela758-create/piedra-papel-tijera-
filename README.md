# Juego: Piedra, Papel o Tijera 🎮

Este proyecto es una aplicación de consola desarrollada en Python que permite jugar al clásico juego de Piedra, Papel o Tijera contra la computadora.

## 📋 Descripción del Proyecto
El sistema cuenta con un menú interactivo, validación de entradas para evitar errores de usuario, control de victorias mediante estructuras condicionales y un bucle repetitivo para jugar múltiples rondas con marcador en tiempo real.

## 📁 Estructura del Repositorio
* `codigo/` - Carpeta destinada a los archivos fuente.
* `diagramas/` - Contiene los diagramas de flujo del proyecto.
* `main.py` - Archivo principal con la ejecución del programa.
* `README.md` - Descripción general de la entrega.

## 🚀 Requisitos e Instalación
* Tener instalado Python 3.x
* Ejecutar el comando en la terminal:
  ```bash
  python main.py
